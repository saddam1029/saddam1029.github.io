About

I'm an Android developer based in Islamabad, working mainly in Kotlin with a Java background, and about five months into building UI with Jetpack Compose alongside XML. Most of my time goes into structuring apps around MVVM and Clean Architecture, so features stay easy to change once the product direction shifts — which, in a software house, it always does.

Outside of code I train and compete as an athlete, and the habit carries over directly: break the work into repeatable sets, track what's actually improving, and don't confuse motion with progress. That's shaped how I approach app architecture as much as anything I've read about it.
