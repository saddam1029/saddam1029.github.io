About

A developer who cares about craft and substance.

I'm an Android developer who builds mobile applications with Kotlin and the modern Android ecosystem. My work centers on creating apps that are genuinely useful — apps that solve real problems and feel good to use.

I work with Kotlin, the Android SDK, and Jetpack libraries to build maintainable, testable applications. I follow MVVM and Clean Architecture patterns to keep code organized, use Coroutines for asynchronous work, and integrate REST APIs with Retrofit and OkHttp.

On the data side, I use Room Database for local persistence and Firebase for backend services, analytics, and crash reporting. I've also worked extensively with Google Maps and location APIs for navigation-based apps.

I care about UI implementation — translating designs into responsive, accessible interfaces with XML and Material Design. Performance matters to me: smooth scrolling, efficient background work, and keeping apps fast on real devices.

Engineering
