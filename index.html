About

I'm an Android developer with two-plus years of experience designing, building, and maintaining production apps in Kotlin and Java, working across XML and, more recently, Jetpack Compose.

Most of my work centers on structuring apps around MVVM and Clean Architecture, using Coroutines for asynchronous work, Room for local persistence, Retrofit for networking, and Firebase where a backend is needed — with Git and GitHub for version control throughout. I care less about using every tool available and more about the app staying easy to change once requirements shift, which they always do.
